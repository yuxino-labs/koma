# Character placement

The [family mascot](logo-assets.md) is a small brand signature. Public and authenticated headers use the compact avatar; help may use the same avatar at a modest size.

The working area prioritizes video input, analysis requirements, saved videos, processing status, and results. Do not restore a large welcome illustration, speech bubbles, decorative character signatures, or repeated mascots in progress and empty states. The user requested a tool-oriented site with less AI-template styling. Character color does not change the neutral interface palette.

The right-hand account menu uses the authenticated user’s GitHub photo or an initial when unavailable. The service’s own mascot must not stand in for the user.

The current mascot is a transparent character cutout on the white interface. Do not restore a circular backing, stars, sparkles, patterns, or a decorative bottom bow.

Use a simple head-and-shoulders portrait with a plain ivory top. Recording accessories, hands and elaborate clothing were explicitly removed; keep the face as the focus.
